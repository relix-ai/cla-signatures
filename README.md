# cla-signatures

Contributor License Agreement signatures for the Relix project.

This repository is maintained automatically by the
[cla-assistant](https://cla-assistant.io) bot. Each signed CLA is
recorded as a JSON entry under `signatures/`.

## Layout

```
signatures/
└── v1/
    └── cla.json     Signature ledger maintained by the bot.
```

## Signing

Open a pull request against any repository under
[github.com/relix-ai](https://github.com/relix-ai). The bot will
comment with a link to sign on the first contribution. Subsequent
contributions do not require re-signing.

The CLA text is in
[`relix/CLA.md`](https://github.com/relix-ai/relix/blob/main/CLA.md).
